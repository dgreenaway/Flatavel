# Laravel Lite Blog

A personal blog built with Laravel as a learning project. There is no database -- posts are Markdown files stored in `content/posts/` and the app reads them directly from the filesystem.

I built this to get my head around how Laravel works: routing, controllers, models, views, middleware, and how it all connects together.

## What it does

- Homepage with a short intro and the 3 latest posts
- Full post list at `/posts`
- Individual post pages with featured image support
- About page
- Contact form that saves messages as JSON files
- Password-protected admin area for writing posts, uploading images, viewing messages, and changing site settings

## Tech used

- Laravel 13
- PHP 8.5
- [spatie/yaml-front-matter](https://github.com/spatie/yaml-front-matter) for reading post metadata
- [league/commonmark](https://github.com/thephpleague/commonmark) for converting Markdown to HTML
- Ceefax-inspired teletext theme with CRT screen effects

## Getting started

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan serve
```

Then visit `http://127.0.0.1:8000`.

## Content directories

These directories are not included in the repo (they contain user content, not code). You need to create them manually after cloning:

```
content/posts/
content/messages/
public/images/posts/
```

You also need to create `content/settings.json` or visit `/admin/settings` after logging in and the app will create it for you.

## Writing posts

Posts live in `content/posts/` as `.md` files. You can write them in the admin area or create them manually. The filename becomes the URL slug, so `my-first-post.md` is available at `/posts/my-first-post`.

Each file needs a YAML front matter block at the top:

```yaml
---
title: My Post Title
date: "2024-03-15"
description: A short summary shown on the post list.
image: my-image.jpg
---

Post content goes here in Markdown.
```

The `image` field is optional. If set, the filename should match an image in `public/images/posts/`.

## Admin area

Visit `/admin/login` to log in. Set your password in `.env`:

```
ADMIN_PASSWORD=yourpasswordhere
```

From the admin area you can create and edit posts, upload images, read contact messages, and update site settings.

## Notes

- `bootstrap/cache/` files are auto-generated by Laravel, do not commit them
- `.env` holds your local config and secrets, never commit it
- Sessions are stored as files so no database is needed
- The date field in post front matter must be quoted, e.g. `date: "2024-03-15"`, otherwise the YAML parser converts it to a timestamp
